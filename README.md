# 🔥 대한민국 소방청 전국 화재상황 종합관제 상황판

대한민국 소방청 공공데이터를 기반으로 실시간 전국 화재 발생 현황, 출동 소방력, 인명/재산 피해, 발화 원인 및 지도 분포를 한눈에 파악할 수 있는 **스마트 재난 안전 관제 웹 대시보드**입니다.

---

## 🌟 주요 기능

1. **실시간 핵심 지표 (KPI) 요약**:
   - 금일 전국 화재 발생 건수 및 증감 추이
   - 현재 진압 / 긴급 출동 건수 (대응단계 표시)
   - 진화 완료(완진) 건수 및 진화율 (%)
   - 인명 피해 현황 (사망 / 부상)
   - 동원 소방차량 및 소방대원 수

2. **인터랙티브 대한민국 화재 분포 지도 (Leaflet.js)**:
   - 다크 모드 재난안전 관제 스타일 타일맵
   - 진행 중인 화재의 실시간 펄스(깜빡임) 애니메이션 마커
   - 마커 클릭 시 소방서, 발화원인, 피해규모 팝업
   - 권역별 퀵 필터 (전국, 수도권, 강원, 충청, 호남, 영남, 제주) 및 원클릭 복귀

3. **심층 화재 분석 차트 (Chart.js)**:
   - **발화 원인 분석**: 부주의, 전기적 요인, 기계적 요인, 방화 등 도넛 차트
   - **시간대별 발생 추이**: 00시 ~ 24시 발생 빈도 영역형 라인 차트
   - **시·도별 발생 현황**: 주요 광역시도별 발생 순위 바 차트

4. **실시간 화재 출동 피드 & 상세 브리핑**:
   - 지역, 소방서, 화재 유형 실시간 검색 및 상태별 필터링
   - 피드 항목 클릭 시 해당 지도 좌표로 부드러운 카메라 이동
   - 타임라인 및 출동 장비/인력이 포함된 상세 모달 지원

5. **소방청 공공데이터 API 연동 및 표준 시뮬레이션 지원**:
   - 공공데이터포털(`data.go.kr`) 일반 인증키(Service Key) 간편 등록
   - 브라우저 CORS 보안 우회 프록시 옵션 제공
   - 인증키가 없거나 서버 점검 중일 때도 즉시 작동하는 **소방청 표준 시뮬레이션 엔진 탑재**

---

## 🔑 공공데이터포털(data.go.kr) 소방청 API 발급 안내

1. **공공데이터포털 접속 및 로그인**:
   - [공공데이터포털(data.go.kr)](https://www.data.go.kr) 접속
2. **데이터셋 검색**:
   - 검색창에 **`소방청 화재발생정보`** 또는 **`소방안전 빅데이터`** 검색
3. **오픈API 활용 신청**:
   - [활용신청] 버튼 클릭 후 개발 목적 선택 (즉시 자동 승인)
4. **인증키 확인 및 상황판에 입력**:
   - [마이페이지] > [데이터활용] > [오픈API]에서 **일반 인증키(Encoding 또는 Decoding)** 복사
   - 본 상황판 우측 상단의 **[API 설정]** 버튼을 눌러 인증키를 입력하고 저장합니다.

## 🚀 배포 방법 (GitHub Pages)

이 프로젝트는 순수 웹 표준(HTML5, CSS3, Vanilla JS)으로 제작되어 서버 없이 **GitHub Pages**를 통해 즉시 무료로 배포할 수 있습니다.

1. **저장소 푸시**:
   ```bash
   git init
   git add .
   git commit -m "feat: 소방청 전국 화재상황 종합관제 상황판 배포"
   git branch -M main
   git remote add origin https://github.com/cjb0948-cloud/fire-dashboard.git
   git push -u origin main
   ```
2. **GitHub Pages 활성화**:
   - GitHub 저장소의 **Settings** > **Pages** 이동
   - **Build and deployment** > Source: `Deploy from a branch`
   - Branch: `main` / `/ (root)` 선택 후 **Save**
   - 약 1~2분 후 `https://cjb0948-cloud.github.io/fire-dashboard/` 주소로 전 세계에 배포됩니다!
